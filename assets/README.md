# Recursos visuales

`images/tacho-vivo.png`: ilustración original generada con la herramienta integrada image_gen, guiada por la skill imagegen. Imagen raster con transparencia para bienvenida y tablero; no sustituye el logotipo original del proyecto. No se utilizaron imágenes de referencia como entrada.

Prompt final:

> Use case: stylized-concept. Asset type: hero illustration for TrackTrash, a professional recycling mobile app for Arequipa, Peru. Create a delightful premium 3D clay illustration of a friendly emerald green smart recycling bin mascot with a small smiling digital face and tiny articulated arms, standing next to neatly separated cardboard, a clear bottle and a small leafy plant. Very subtle pale mint silhouette of the Misti volcano behind it. Warm approachable environmental technology, sculptural soft rounded forms, premium studio lighting and soft contact shadows. Palette deep emerald #075E46, fresh green #BDEBAD, pale cream mint. Square composition with ample clear space around the subject, mascot centered, no lettering, no logos, no watermark, no interface, no border. Transparent background, clean alpha edges, usable at 250 pixels in a mobile app. This is an original character illustration, not a logo.

Las animaciones se implementan en Flutter con transiciones de entrada y estados; no se utilizan videos o imágenes descargadas de terceros. El mapa mantiene atribución a OpenStreetMap y permite configurar el proveedor de teselas mediante MAP_TILE_URL.
